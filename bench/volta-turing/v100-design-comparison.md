The current `v20` native fused-IQ prompt path decodes GGUF IQ/Q2 bytes to INT8 fragments, quantizes activations to Q8, and uses `mma.m16n8k32` on modern CUDA; its sm75 admission is limited to the canonical Q2_0 pack. Its existing sm75 and older-GPU MMQ fallbacks must remain available. The Volta references use FP16 tensor-core products, so matching dequantized weights alone does not establish equal logits, routing, acceptance or final quality. The QPN scheduling concept is also architecture-specific: sm70 fragment lane maps and sm75 integer MMA layouts differ.

Practical next experiment for TODO 19.3/19.4: prototype an original-byte IQ4_NL down path and an IQ2_S gate/up path only on their matching layers, in an isolated sm70 build. Screen exact packed-byte round trips, FP64 weight references, adversarial activation scales, mixed-format layer dispatch, real routed-row counts, registers/spills, and full GU+epilogue+down call cost. Then run V100 same-day ABBA with fixed cache/chunk budgets and teacher-forced/task gates before selecting any sm70 default. The RTX 2060 SUPER can validate compilation or an independently admitted sm75 variant but cannot substitute for V100 timing.
