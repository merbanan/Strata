# Per-window decode trace (diagnostic)

`STRATA_TRACE_WINDOWS=1` writes one `strata window trace:` line to the engine's stderr for each committed verify window. Unset and `0` leave this diagnostic off. Serial windows include a request-local ID, round, position, total/MTP/chain width, source flags, accepted/offered drafts, verify/commit/draft wall time, and deltas for CPU misses and entries, VRAM hits, PCIe experts, CPU pool time and GPU stage time. These counters are for the complete verify window, not individual layers or format cells. Pipeline windows overlap; their lines label dispatch as `overlapped` and intentionally omit per-window dispatch attribution.

The source builds into the sm75 v20 engine, and that binary passes `--help` without loading a model. The build was completed before moving temporary artifacts to `/run/media/benjamin/TMP/strata-codex-20261023/`; the relocated binary is `strata-v20-attention-build/strata`. Runtime trace output, parity and overhead remain untested because the user asked to free RAM and the model service is stopped. Do not use this diagnostic to select an expert mode until a model run checks line counts against DONE totals, exact output/acceptance, and whether tracing perturbs timings. GPU overlap requires separate attribution or external profiling.
