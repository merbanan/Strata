# Per-window decode trace (diagnostic)

`STRATA_TRACE_WINDOWS=1` writes one `strata window trace:` line to the engine's stderr for each committed verify window. Unset and `0` leave this diagnostic off. Serial windows include a request-local ID, round, position, total/MTP/chain width, source flags, accepted/offered drafts, verify/commit/draft wall time, and deltas for CPU misses and entries, VRAM hits, PCIe experts, CPU pool time and GPU stage time. These counters are for the complete verify window, not individual layers or format cells. Pipeline windows overlap; their lines label dispatch as `overlapped` and intentionally omit per-window dispatch attribution.

The initial source build passed on sm75 before temporary artifacts moved to `/run/media/benjamin/TMP/strata-codex-20261023/`. Runtime validation followed in the gate below. The trace does not identify expert format cells or assign overlapped GPU dispatch to an individual verdict; those questions require separate attribution or external profiling.

## RTX 2060 SUPER runtime gate (2026-10-24)

The current IQ3_XXS/K8V4 model ran a fresh base/trace/trace/base full-model ABBA. The only configuration difference was `STRATA_TRACE_WINDOWS=0/1`; all four legs had 1,403 expert-cache slots, 6,400-token auto chunks and a 39.60 GiB pinned complement. At 4K and 16K prompts with 256 generated tokens, all four legs matched request hashes, text, generated tokens and logged work. Both traced legs independently emitted 124 and 125 serial window records for the 4K and 16K requests, with contiguous round numbers. Their complete sequences of widths, source flags and accepted/offered drafts match each other. Summed accepted/offered counts match each request's engine metrics exactly. The 156-token probe and benchmark warmup also have contiguous traces; the warmup's totals match its metrics. The independent [audit script](audit-window-trace.py) saved its hash-bound report as `/run/media/benjamin/TMP/strata-v20-window-trace/full-20261024a/audit.json`.

The 4K request used widths 1/2/3/8 in 22/17/84/1 windows; the 16K request used widths 1/2/3 in 25/23/77 windows. All were serial and `chain=0`. Whole-window CPU misses were 96,915/72,502 and PCIe experts 5,239/2,540 at 4K/16K in the first traced leg. Those counters cannot identify expert format cells or assign overlapped pipeline dispatch to a verdict.

Paired trace-on/off decode-rate ratios were 1.011/1.036 at 4K and 1.007/1.027 at 16K; paired prefill ratios were 1.001/1.044 and 0.999/1.000. The second 4K baseline leg was slower, so these numbers indicate no detectable trace overhead in this screen, not a trace speedup. Each traced engine log was about 94 KiB. Raw configs, server/engine logs, responses and timings are under `/run/media/benjamin/TMP/strata-v20-window-trace/full-20261024a/`. The benchmark stopped its units and released GPU memory afterward.

The `pipeline=1` source branch requires a multi-GPU layer split; this single RTX 2060 SUPER run cannot qualify its runtime or per-stage attribution. Pinned-stage per-stream fences from #3483 remain under the separate host-staging audit. The trace is now usable for single-GPU window-width and complete-window dispatch accounting, with profiling cost excluded from speed claims.
