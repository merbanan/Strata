# Small-query K8V4 prompt attention on RTX 2060 SUPER

TODO 12.5 asks whether sharing K/V reads across 2–8 prompt queries is useful beyond the completed 16-query tile screen and the verifier scorer's existing within-call reuse.

`STRATA_PA_ROUTE_TRACE=1` logs the chosen attention route and query count at the actual prefill call, without changing the default dispatch. With cross-request prompt caching disabled, six direct-engine requests used pinned prefixes of 2, 4, 8, 16, 64 and 256 tokens and one subsequent verifier-window token. Every request read its entire prefix through batched prefill, with zero reused tokens. Each of the 12 QSA layers used the K8V4 `qsa_prompt_attn_batch` route at each size: 72 route records total. Raw configuration, token-source hash, engine log and summary are under `/run/media/benjamin/TMP/strata-v20-pa-small/trace-20261024b/`. The first attempted trace retained the prompt cache and was invalid after its 2-query case reused a three-token prefix; it is preserved as `trace-20261024a` and excluded.

The installed sm75 K8V4 batch kernel launches one CTA per `(query, KV head)`, so 2, 4 and 8 queries launch only 4, 8 and 16 CTAs on this 34-SM GPU. An implementation that combines those queries inside a CTA to reuse K/V would reduce the CTA count further unless it also partitions the key work and merges partial outputs. The latter adds synchronization/reduction work and must preserve the FP32 accumulation and causal tail boundaries.

An isolated `qsa_prompt_attn_parity` screen compared the existing decode-style fallback against the current batch kernel with 20–30 repetitions. At 4K context, old/batch call times were 0.078/0.459 ms (2 queries), 0.157/0.463 ms (4) and 0.293/0.463 ms (8). At 32K they were 0.087/0.377, 0.164/0.377 and 0.303/0.377 ms. The current batch path is underoccupied at these sizes. The fallback is faster but produces a different result: its maximum error against the fixture's FP64 reference is about 0.0012–0.0020, while the batch path's is at most 8.6e-6 in these cases. Thus the fallback timing is an opportunity signal, not a parity-qualified replacement. All fixture parity checks passed their existing bounds. Raw logs are `/run/media/benjamin/TMP/strata-v20-pa-small/isolated-{4k,32k}-20261024a.log`.

The traced 2–8-query calls were fresh, very short prefixes; their whole-prompt times were 321–376 ms, and no real long-context 2–8-query prompt calls were established. Key sharing alone does not address the observed low CTA occupancy and has no demonstrated full-model gain. Hold a shared-key implementation on this RTX 2060 SUPER route. Reopen only with real long-context call frequency and a candidate that maintains numerical behavior and improves complete request timing.
